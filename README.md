# 娜娜莉桌宠

**Nanally Desktop Pet**

把娜娜莉带到桌面，让她陪你聊天、看图、工作，也沿着窗口倒着散步。

Windows x64 · WPF · PNG 序列帧 · AI 图文聊天 · 重力行走

基于 **LorisYounger 及贡献者的 VPet 源码**开发的独立应用 · 非官方同人项目

## 项目特色

| 特色 | 可以做什么 |
|---|---|
| 娜娜莉专属形象 | 待机、眨眼、左右步行、摸头、摸身体、提起、下落、睡眠，以及进食、饮水、工作、学习和玩耍 |
| 重力操控 | 脚贴着屏幕内缘或所选应用窗口外缘行走；侧身、倒置、转角时继续迈步 |
| AI 图文聊天 | 发送文字、PNG/JPG 或剪贴板截图；结合上下文追问，回复联动六种情绪与嘴型 |
| 陪伴与日常 | 从陪伴空间进入聊天、日常活动、物品、成长与设置，保留喂养、商店、背包和本地存档 |
| 独立运行 | 不需要安装原版 VPet 或 Steam；安装包包含运行依赖，用户无需安装 .NET SDK |

> AI 回复以文字气泡与表情/嘴型呈现。当前版本没有语音、TTS 或声音克隆功能。

## 安装与第一次启动

1. 运行项目提供的 `Nanally-DesktopPet-1.0.0-win-x64-Setup.exe`，按提示完成安装。
2. 从开始菜单“娜娜莉桌宠”或所创建的桌面快捷方式启动。
3. 娜娜莉出现后，先尝试**短按头部摸头**，再尝试**长按头部提起并拖动**。
4. **右键娜娜莉**打开操作面板；也可以右键系统托盘中的娜娜莉图标。
5. 要使用 AI，再按下文填写模型服务设置。基础动画、拖动与日常互动可以离线使用。

安装面向 **Windows 10/11 x64**，默认安装到当前用户的程序目录。安装、更新或卸载前，请从菜单正常退出桌宠，避免覆盖正在使用的程序文件。

## 使用教程

### 1. 摸头、提起与改变位置

**普通模式下，移动位置的完整操作是：长按头部 → 出现提起姿势 → 保持按住并拖动 → 松开。**

| 操作 | 如何操作 | 娜娜莉的反应 |
|---|---|---|
| 摸头 | 头部短按左键后松开 | 播放摸头互动 |
| 摸身体 | 身体区域短按左键后松开 | 播放身体互动 |
| 提起 | 在头部按住左键，等提起姿势出现 | 进入提起状态；默认长按判定约 **0.3 秒**，以实际设置为准 |
| 拖到别处 | 提起后继续按住左键移动鼠标 | 跟随鼠标移动；不要在提起前就快速划走 |
| 自然下落 | 拖动到新位置后松开左键 | 先播放松手过渡，随后向下落地并恢复普通状态 |
| 下落前再次单击 | 松手后、仍在过渡动作时，再单击娜娜莉 | 打断这次松手后的下落流程，转回普通互动 |
| 下落中再次单击 | 她已经往下掉时，再单击娜娜莉 | 中断当前下落；需要重新移动时，再长按头部提起 |
| 打开操作面板 | 右键娜娜莉 | 显示投喂、面板、互动、系统等入口 |

**想让她暂时停在松手的位置，可以在松手过渡期间再单击一次。**这不是“永久锁定坐标”：恢复普通状态后，她仍可能自主活动；后续重新提起再松手，也会产生新的下落。

短按与长按是两种手势；“松手后再单击”也不要求双击。工作、睡眠、对话动作及重力行走有各自的状态规则，遇到行为不同，先检查当前模式。

### 2. 屏幕内缘重力行走

娜娜莉使用重力操控，**脚始终朝向支撑边缘**：在底边正立，在侧边横向，在顶边倒置，不使用手部悬挂或攀爬。

1. 右键娜娜莉，进入 **互动 → 重力贴边行走**，再次点击可停止。
2. 也可右键托盘图标，在 **重力贴边行走** 子菜单勾选“启用”。
3. 从托盘子菜单选择 **底边、右边、顶边（倒置）、左边**，或点击 **反向行走**。
4. 启动前需允许移动，并结束工作、睡眠等占用动作。

重力模式下可以**按住角色并直接拖动**。在屏幕内缘模式松开后，她会重新吸附到最近的屏幕边缘并继续行走，**不会使用普通模式的自由下落流程**。点击头部、身体仍可互动；转角中的互动可能等走到安全位置后再播放。

### 3. 普通应用窗口外缘行走

这是沿某个软件窗口的**外侧边框**散步：窗口顶部正立，右侧横向，底部倒置，左侧反向横身。

1. 打开一个**未最大化**的普通窗口，在窗口四周留出足够空间。
2. 右键娜娜莉，选择 **互动 → 窗口外缘行走**；托盘也有同名入口。
3. 在列表中选择目标窗口，点击 **开始贴边**。窗口未列出时可刷新。
4. 用 **停止贴边** 或“互动 → 重力贴边行走”结束；托盘的“反向行走”可改变当前方向。

| 窗口或鼠标操作 | 结果 |
|---|---|
| 移动或调整目标窗口大小 | 娜娜莉随边缘更新位置 |
| 最小化、隐藏、最大化或关闭目标 | 安全解除附着，恢复普通状态 |
| 周围空间不足或路径被其他窗口遮挡 | 可能反向或停止，不保证能绕每个窗口完整一圈 |
| 按住并拖走娜娜莉，再松开 | 结束这次窗口附着，不会吸回远处的原窗口 |
| 恢复刚才最小化的窗口 | 不自动重新附着，需要再次选择 |
| 在托盘中选择屏幕顶边、底边等 | 切回屏幕内缘行走 |

**如果只在某一侧来回走，先把窗口缩小、移离屏幕边缘，并让其他窗口避开转角区域；也可缩小桌宠再试。**窗口四周必须放得下角色的完整画布，肉眼看到少量空白不一定足够。

### 4. AI 聊天设置

1. 右键娜娜莉，进入 **系统 → 设置面板 → AI 设置**；托盘“AI 设置”也打开同一页。
2. 填写兼容 **Chat Completions** 的服务地址、模型名称和自己的 API Key。
3. 点击 **保存设置**，确认页面提示“设置已保存”。
4. 进入 **互动 → 和娜娜莉聊聊**，输入文字并点击发送，或按 **Ctrl+Enter**。

项目默认预填以下服务参数；**不附送 API Key 或模型额度**：

| 项目 | 默认值 |
|---|---|
| Base URL | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 模型 | `qwen3.8-flash` |
| 超时 | 60 秒，可在设置中调整 |
| 对话上下文 | 最近 6 轮，可在设置中调整 |

可以修改娜娜莉的人设与上下文设置。她会根据聊天内容选择自身回应的 `normal`、`happy`、`angry`、`surprised`、`sad`、`sleepy` 六种情绪，无需每次明确下达表情指令；未知情绪安全回退到普通表情。

“停止”用于取消当前回复和动作；关闭聊天窗口也会取消当前轮次。网络错误会提示重试，基础桌宠仍可使用。更换模型服务地址时，需要重新填写对应密钥。

### 5. 发图片、截图与追问

有三种添加图片的方式：

- 点击 **添加图片**，选择 PNG/JPG。
- 将 PNG/JPG 文件拖入聊天窗口。
- 用系统截图工具截图，再在聊天输入框按 **Ctrl+V** 粘贴。

确认缩略图后，可以加一句“帮我看看这里有什么问题”，也可以只发送图片。缩略图支持点击查看、移除；**每条最多 4 张，单张原文件不超过 10 MiB**。发送失败会保留草稿，成功后可以继续追问同一张图。

图片发送前会处理方向、缩小过大的尺寸并去除元数据；原件最长边可能缩至 2048，因此不保证能看清原图中极小的文字。上下文和图片显示有容量限制，较旧图片会按整轮淘汰；需要再次讨论时可重新附图。

> **只有点击发送后，图片才会交给你配置的模型服务。**程序不自动截屏、不持续监视屏幕，也不使用额外图床。图片只保存在当前会话内存中，清空上下文或退出后释放；模型服务如何处理请求，以你所选服务的规则为准。

图片聊天要求所选模型支持图片输入。兼容 OpenAI 的地址并不自动意味着该服务或模型支持看图。

### 6. 日常活动与快捷恢复

右键娜娜莉，从 **空间 → 打开陪伴空间** 进入集中导航，再选择聊天、日常活动、物品、成长或设置。也可使用原有投喂、面板等快捷入口。

- **工作、学习、玩耍**：从工作面板选择活动；对应娜娜莉整理资料、看书、玩掌机等动画。是否允许开始取决于当前状态和活动条件。
- **进食、饮水与背包**：通过物品商店和背包使用可用物品；余额、库存和生活数值仍参与结算。
- **娜娜莉待机**：互动菜单中的同名入口可开始/停止待机演示，工作、睡眠或重力行走时不能启动。
- **正常退出**：使用系统菜单或托盘的“退出桌宠”，便于保存当前状态。

| 遇到的情况 | 可以先这样处理 |
|---|---|
| 点击或拖动没有反应 | 从托盘检查是否启用了“鼠标穿透”，先关闭穿透 |
| 被其他窗口挡住 | 从托盘启用“置于顶层” |
| 位置或姿态异常、找不到桌宠 | 从托盘选择“重置位置与状态”，返回主屏幕中央并恢复普通状态 |
| 重力行走无法启动 | 检查是否允许移动，先结束工作、睡眠或当前占用动作 |
| AI 提示认证失败 | 检查服务地址与 API Key，保存后重试；不要把密钥贴进问题反馈 |

## 相对 VPet 的改动

本项目是**直接修改 VPet 源码的独立应用**，不只是替换皮肤或要求用户安装的 MOD。以下说明针对本项目固定的上游基线，不代表对 VPet 后续版本的完整比较。

| 领域 | 本项目的具体调整 |
|---|---|
| 产品范围 | 从通用桌宠宿主收敛为娜娜莉专用应用；默认启动娜娜莉，移除其他角色选择、工坊和通用代码插件管理入口，旧角色选择迁回娜娜莉 |
| 角色与动画 | 删除原角色专属模型、图库、生日/活动物品和界面插画；接入娜娜莉 PNG 动作、左右交替步态、六情绪动态嘴型、交互及活动动画，工作面板等插图同步替换 |
| 界面与入口 | 增加娜娜莉共享窗口外框、控件样式和陪伴空间导航；重排聊天、日常、商店、背包、存档与成长界面，菜单按互动/系统职责整理；应用、托盘与后台图标改为娜娜莉头像 |
| 屏幕重力行走 | 新增脚底支撑边缘、角色整体旋转、侧身/倒置、转角续播、反向和交互打断；气泡与菜单保持正向，触碰区域随角色朝向换算 |
| 应用窗口外缘行走 | 新增手动选窗、四边外侧行走、外凸转角、目标移动/缩放跟随，以及目标失效、遮挡和空间不足时的恢复 |
| 普通移动与下落 | 普通位移改为渲染时钟按经过时间推进，减少位置跳动；提起释放后的过渡、下落和落地由独立控制器协调，支持鼠标打断；没有靠增加或修改冻结步态帧来改变观感 |
| AI 对话 | 使用源码内置的兼容 Chat Completions 适配器和本项目设置页，提供人设、有限上下文、六情绪映射、取消、超时及异常恢复，不要求另装 AI 插件 |
| 图片聊天 | 新增文件选择、拖放与截图粘贴、预览、纯图/图文消息、带图追问，以及图片解码、传输与内存上限；沿用文字/情绪回复协议 |
| 存档与凭据 | 运行资源与用户数据分离；存档使用不可变快照、串行原子写入；API Key 用当前 Windows 账户 DPAPI 加密，并绑定模型服务地址 |
| 稳定性与性能 | 增加异步取消和过时回调保护、事件解除、有界日志与轮换、内容摘要缓存身份、旋转对象复用；图片缩略图独立缩小，编解码限制并发 |
| 服务与依赖清理 | 删除 Steam 初始化、工坊、联机、云存档、排行榜、上游遥测/反馈及贡献兑换相关实现与依赖；当前产品不提供语音、TTS或声音复刻 |
| 构建与分发 | 主程序改名为 `Nanally.DesktopPet.exe`；保留三个必要的同源工程，移除生产导出中的开发测试/缓存/备用大稿与多余文档，使用系统字体，并提供自包含发布和按用户安装的 EXE 安装器 |

**继续复用的基础**包括 VPet 的透明窗口、PNG 动画组织、基础交互、养成数值、工作、物品、背包和存档机制，以及 Core / Windows.Interface 工程。必要的上游版权声明和引擎命名空间保留；没有将这些基础能力宣称为本项目原创。

## 常见问题与当前边界

- **需要 Steam、原版 VPet 或 .NET SDK 吗？**使用自包含安装包无需安装它们；从源码编译才需要 SDK。
- **需要联网吗？**基础桌宠可以离线使用；AI 请求需要连接你设置的模型服务，并可能消耗该服务额度。
- **会自动朗读回复吗？**不会。当前只显示文字与嘴型/表情，没有语音模块。
- **为什么只在窗口某一边走？**可能是转角或其他边空间不足、被遮挡；请按窗口行走教程调整。没有自动跨窗口转移功能。
- **源码里为什么仍有 VPet 命名？**它来自实际复用的引擎和接口，同时保留开源来源；不表示运行时依赖原版程序或 Steam。
- **当前验证范围是什么？**已完成图文请求与真实 WPF 交互的受控测试、实际嘴型播放检查，以及隔离安装/启动/卸载；真实云模型看图尚无通过证据，干净机器、升级迁移、多屏和混合 DPI 仍需继续验证。
- **Windows 显示未知发布者？**当前安装包未数字签名。

## 从源码构建

需要 **Windows 10/11 x64、PowerShell 7、.NET 10 SDK x64**。首次构建需要联网恢复 NuGet 依赖。

```powershell
pwsh -NoProfile -File ./build.ps1
```

启动文件：`build/Nanally/Release/Nanally.DesktopPet.exe`。

生成包含运行依赖的 Windows x64 目录：

```powershell
pwsh -NoProfile -File ./publish.ps1
```

输出：`dist/Nanally/win-x64/`。分发这个目录时必须包含依赖和素材，不能只复制其中的 EXE；发布过程不裁剪 WPF/反射代码。

<details>
<summary><strong>直接构建项目与生成 EXE 安装包</strong></summary>

直接构建主项目：

```powershell
dotnet build src/VPet/VPet-Simulator.Windows/VPet-Simulator.Windows.csproj -c Release -p:Platform=x64
```

生成安装包需另外安装 **Inno Setup 7**。先执行 `publish.ps1`，再从仓库根目录运行以下命令；把 `ISCC.exe` 换成实际编译器位置：

```powershell
$runtime = Join-Path $PWD 'dist/Nanally/win-x64'
$output = Join-Path $PWD 'dist/installers'
& 'C:/path/to/Inno Setup 7/ISCC.exe' "/DRuntimeDir=$runtime" "/DOutputDir=$output" ./installer/Nanally.iss
```

安装器按当前用户安装，卸载默认保留用户数据。

</details>
